# Memobird G2C 打印接入经验

- G2C 官方开放平台采用云打印，不是浏览器局域网或蓝牙自动发现：先用 `setuserbind` 结合开发者 AK、设备编号与自定义用户标识取得 `showapi_userid`，再调用 `printpaper`。
- 官方文本协议要求中文先编码为 GBK，再做 Base64，并在内容前添加 `T:`。直接使用 UTF-8 Base64 会导致中文输出异常。
- 官方接口仍为 HTTP，且 AK 不应进入前端包或浏览器持久化。Web 应用应由仅监听本机地址的 Node 适配服务代理请求，以规避浏览器混合内容、CORS 和凭据暴露问题。
- 无开发者 AK 时，保留 58mm 系统打印作为可用降级路径；浏览器不支持自动高度的 `@page`，需要给出明确纸宽与纸高，连续纸最终以打印机驱动设置为准。
