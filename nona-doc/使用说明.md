# 饭点 · 芯烨小票台

## 启动

```bash
npm install
npm run dev
```

也可使用 `npm run start`。页面默认地址为 `http://127.0.0.1:5173`，本地打印适配服务地址为 `http://127.0.0.1:8787`。

## 菜单配置

店铺与菜品位于 `src/data/shops.json`。价格使用“分”为单位，例如 `3000` 表示 30 元，以避免浮点金额误差。

每家店至少配置一项 `main`。可选分类为：

- `main`：主食，每张小票固定选择一项。
- `addon`：加料。
- `side`：小菜。
- `drink`：饮料，每张小票最多选择一项。

## 芯烨 XP-80U

打印机为 80mm 热敏、网口、ESC/POS。本机 Node 服务把小票编码成 GB18030，发到打印机的 9100 端口。店名用倍宽倍高居中，打完走纸并半切。

在页面的“芯烨 XP-80U”设置里填写 IP，或复制 `.env.example` 为 `.env.local`：

```properties
PRINTER_HOST=192.168.1.100
PRINTER_PORT=9100
```

`.env.local` 已加入忽略规则。页面上的地址只对当前进程生效，刷新状态会再探一次 9100 端口。

IP 印在自检页上：按住走纸键再开机。芯烨这一档默认 Font A 为 48 列（汉字 24 个）。若分隔线折行，把机底 DIP 的“每行字符”拨到 48 列，通常是 OFF。

“系统打印”仍可用。浏览器纸张按 80mm 连续纸设置；若走操作系统驱动，以驱动里的 80mm 纸宽为准。

## 时间规则

生成时间位于 `18:35:01–20:20:59`，以 `19:18:37` 附近为分布峰值。结果精确到秒，并避开整点、五分钟整数以及整十秒等机械组合。
